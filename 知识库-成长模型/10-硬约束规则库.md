## 一、规则结构 HardConstraintRule

```ts
interface HardConstraintRule {
  type: HardConstraint["type"];
  /** 压力函数：f(当前能力, 目标值, deadline, now) → pressure 0-1 */
  pressureFunction: (current: string | null, target: string, deadline: string | null, now: Date, profile: DecisionProfile) => number;
  /** 紧迫度规则：deadline + now → 紧急/中/低 */
  urgencyRule: (deadline: string | null, now: Date) => "紧急" | "中" | "低";
  /** 影响规则：goal → 高/中/低（该硬约束对该目标的影响程度） */
  impactRule: (goal: Goal) => "高" | "中" | "低";
}
```

## 二、5 类硬约束规则

### 1. language_requirement（语言门槛，如雅思6.5大二前）
- **pressureFunction**：current=englishLevel（none/cet/ielts_toefl），target=ielts_6.5/ielts_7.0 等
  - current=none + target=ielts_6.5 → 差距大（差2档），pressure 高
  - current=cet + target=ielts_6.5 → 差1档，pressure 中
  - current=ielts_toefl + target=ielts_6.5 → 达标，pressure 低
  - **叠加 urgency**：剩余 ≤3月 → pressure ×1.3（紧急加压）
- **urgencyRule**：deadline=sophomore_end → 算距大二结束月数；≤3月紧急 / ≤6月中 / >6月低
- **impactRule**：goal=abroad → 高（出国核心门槛）；goal=baoyan → 中；其余 → 低

### 2. gpa_requirement（绩点门槛，如保研前20%）
- **pressureFunction**：current=gpaTier（below/top50/top20/top5），target=top20/top5
  - current=below + target=top20 → 差2档，pressure 高
  - current=top50 + target=top20 → 差1档，pressure 中
  - current=top20/top5 + target=top20 → 达标，pressure 低
- **urgencyRule**：大三+未达 → 紧急（保研资格窗口收窄）；大二 → 中；大一 → 低
- **impactRule**：goal=baoyan → 高；goal=scholarship → 中；其余 → 低

### 3. internship_requirement（实习门槛，如大厂return offer）
- **pressureFunction**：current=internshipLevel（none/has），target=big_tech_return
  - none + target → pressure 高；has + target → pressure 低
- **urgencyRule**：大三下春招季 → 紧急；大三上 → 中；大二 → 低
- **impactRule**：goal=employment → 高；其余 → 低

### 4. certificate（证书，如教资/法考）
- **pressureFunction**：current=备考进度（无字段时按 none 估），target=证书
  - 未备考 + 考试前 ≤3月 → pressure 高
- **urgencyRule**：考试前 ≤3月 → 紧急；≤6月中；>6月低
- **impactRule**：goal=employment（特定行业）→ 中；其余 → 低

### 5. personal_plan（个人计划，自定义）
- **pressureFunction**：current=进度（无字段时按 none 估），target=用户自定义
  - 无进度 + deadline ≤3月 → pressure 高
- **urgencyRule**：deadline ≤3月 → 紧急；≤6月中；>6月低
- **impactRule**：用户自定义（默认中）

## 三、pressure 计算（hardConstraintPressure 第8因子）

```
pressure = pressureFunction(current, target, deadline, now, profile)   // 0-1
urgency  = urgencyRule(deadline, now)                                   // 紧急/中/低
impact   = impactRule(goal)                                             // 高/中/低

hardConstraintPressure_score = pressure × urgency权重 × impact权重 × 30   // 归一到 0-30（与 goalMatch 量级一致）
  urgency权重: 紧急=1.0 / 中=0.7 / 低=0.4
  impact权重: 高=1.0 / 中=0.6 / 低=0.3
```

- **只 user_declared 进**（source 强约束，system_inferred 不算）。
- 多硬约束同时相关 → 取 max pressure（不叠加，避免无限加压）。
- 无相关硬约束 → pressure 0（不评）。
- reason："由于你设置了[X截止要求]（差距Y+剩余Z月→pressure W），该任务存在明确截止压力，优先级提升"（**UI 透明归因用户输入**）。
