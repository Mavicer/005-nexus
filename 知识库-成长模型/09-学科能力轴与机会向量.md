## 一、为什么用向量（取代枚举）

枚举架构（majorDirection 9 值 + inferSubtype 关键词特调 + knowledge 只打通 AI 保研）的本质问题：**特调**。清华 AI 有专门规则很漂亮，"南京中医药康复"落 `other` 走 base = 没个性化 = 伪智能。枚举永远覆盖不全（康复/中医药/兽医/农林/法学细分/任意搭配）。

**向量方案**：专业 = 一组学科能力轴的权重向量（7 轴），机会 = 同一组轴的价值向量，适配度 = 两向量点积。**任意专业都能算**（康复 clinical 轴 0.9 × 临床实习 clinical=1.0 = 高；康复 × ACM = 低），不靠"康复"在枚举表。这才是真综合分析（owner 铁律①推理非匹配、③知识库当大脑、⑨改任意维度结果都变）。

## 二、7 学科能力轴定义

每轴 0.0-1.0（一位小数），表示该专业/机会在此能力维度的强度。

| key | 含义 | 高分专业示例（0.7-1.0） | 高分机会示例 |
|---|---|---|---|
| `math` | 数理/统计/逻辑推演 | 数学/物理/统计/AI/金融工程 | ACM、数学建模、数学竞赛 |
| `research` | 学术科研/论文产出 | AI/理科/医学基础/材料 | 科研训练、大创、论文 |
| `clinical` | 临床/动手/现场实践 | 临床/康复/护理/口腔/兽医 | 临床实习/规培、临床竞赛 |
| `engineering` | 工程/系统/建造 | 计算机/电子/机械/土木 | 开源贡献、工程竞赛、电子设计 |
| `humanities` | 文科/社科/理论 | 文史哲/法学/社会学 | 案例竞赛、人文社科竞赛 |
| `business` | 经济/管理/商业 | 经济/管理/金融/市场 | 案例赛、市场调查、创业竞赛 |
| `arts` | 设计/艺术/创意 | 美术/设计/传媒/广告 | 广告艺术大赛、设计竞赛 |

> 7 轴覆盖全学科：医学→clinical 高、农林→clinical+research、法学→humanities+business、艺术→arts。任意专业都能归一到这 7 轴的某组合。

## 六、适配度计算（majorMatchScore）

```
majorMatch = Σ(专业向量[axis] × 机会向量[axis] × 轴权重)   // Phase A 轴权重均等=1
归一: score = round(dotSum / maxPossibleDot × 25)           // 归一到 0-25（与枚举版量级一致）
dominantAxis = argmax(专业向量[axis] × 机会向量[axis])      // 点积贡献最大的轴，给 reason
```

- maxPossibleDot：从 OPPORTUNITY_VECTORS 实际算（该机会向量各轴平方和的开方归一，或固定标定值注释）。4.2 review 给量级对照表。
- 量级对照（4.2 验证）：AI×ACM 应≈25（接近枚举版 S）、康复×临床应≈20（接近枚举版 S）、康复×ACM 应≈8（接近枚举版 B）、归一失败中性×任意应≈10（接近枚举版 A 中位）。

## 七、维护约束

1. **改规则改 md + TS 同步**：本 md 是真理源，`major-vector.ts` 是镜像。改某门类向量/机会向量/微调，md 和 TS 一起改，附 commit 说明。
2. **不编造具体分数**：向量值 0-1 定性能力权重，非"保研加 X 分"。majorMatch 归一分是适配度排序用（0-25），不是真实保研加分。
3. **标经验参考**：向量标定是经验方向（如医学 clinical=0.9、哲学 humanities=0.9），因校因专业而异，可演进。
4. **7 轴扩展**：Phase A 7 轴。若发现覆盖不全（如"语言能力"独立轴），Phase B/C 加轴（向量维度扩展，不破坏架构）。
5. **clinical-internship subtype** 是康复场景验证必要覆盖，非扩范围（4.1 顺带补 inferSubtype 关键词）。
