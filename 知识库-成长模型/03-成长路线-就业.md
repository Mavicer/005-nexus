# 成长路线 · 就业目标

> 经验参考，非官方规则。因行业/岗位/学校不同而变化。

## 一、核心逻辑

就业导向看「**能做事的证据**」：实习 > 项目 > 竞赛 > 学业。技术岗尤其看重可验证的项目与开源贡献；非技术岗看实习 + 综合素质。

## 二、年级准备路线（经验）

### 大一 · 探索打基础
- 学业：保证不挂科、绩点中等偏上即可（就业看权重低于保研）。
- 探索方向：了解各行业/岗位（互联网/金融/快消/国企/选调等），明确兴趣。
- 基础技能：编程/办公/英语打底。
- 社团/学生工作：锻炼软技能（沟通/组织），积累人脉。

### 大二 · 建项目
- 技术岗：做个人项目（GitHub 放）、刷题（LeetCode 等）、参与开源。
- 非技术岗：找第一份相关实习（日常实习/远程）。
- 竞赛：参加对口竞赛（互联网+/挑战杯/数学建模），拿奖作简历亮点。
- 信息：关注目标公司校招节奏（大厂春招/秋招、暑期实习）。

### 大三 · 冲实习拿 return offer
- **暑期实习是关键**（大三暑假）：大厂暑期实习转正率高（经验，各厂不同），是秋招前最重要跳板。
- 上学期：刷题、改简历、投暑期实习（3-5 月投递，经验时间）。
- 暑假：实习争取 return offer。
- 参加大厂训练营（字节青训营/腾讯犀牛鸟/美团北斗等，经验）。

### 大四 · 秋招春招
- 9-11 月秋招（金九银十，经验）。
- 3-4 月春招补录。
- 拿 offer 后准备入职；考研/考公可作备选。

## 三、关键准备要素（经验权重）

| 要素 | 经验权重 | 说明 |
|---|---|---|
| 实习经历 | 最高 | 大厂实习 + return offer 最硬 |
| 项目经历 | 高 | GitHub 项目/开源贡献，技术岗尤甚 |
| 算法/刷题 | 高（技术岗） | 笔试面试门槛 |
| 高认可竞赛 | 中 | 简历亮点，区分度 |
| 英语 | 中 | 外企/出海岗有门槛 |
| 学业成绩 | 中 | 部分国企/选调有要求 |
| 软技能/人脉 | 中 | 非技术岗重要 |

## 四、常见误区（经验）

- 只刷题无项目 → 面试讲不出深度。
- 实习小公司堆数量 → 一段大厂对口 > 多段小厂杂活。
- 忽视秋招节奏 → 错过金九银十。
- 简历海投不针对 → 应按岗位定制。
- 技术岗不碰开源 → 开源贡献是高级岗硬通货。

## 五、待验证

- 各大厂训练营招募条件与时间（字节青训营/腾讯犀牛鸟/美团北斗等）。
- 校招时间节点（春招/秋招/暑期实习投递月）。
