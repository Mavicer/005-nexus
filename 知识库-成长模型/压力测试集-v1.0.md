# 成长决策系统压力测试集 v1.0

> 性质：**验收基准，非训练数据**。5 用户画像 + 总验收标准，用于验证系统是否真个性化决策而非伪智能推荐。
> 红线：绝不进知识库成规则；系统跑通靠通用机制；反特调测试换等价画像结果须一致。
> 维护：Agent B。owner 2026-07-20 下达。

## 测试目的

验证成长规划系统是否具备真实个性化决策能力，而非简单信息推荐。系统须能根据：学校层次 / 专业方向 / 年级阶段 / 目标类型 / 当前能力 / 时间约束 / 资源条件 / 风险偏好，综合判断用户当前最优成长路径。

**禁止出现**：所有用户推荐同一套竞赛列表 / 只根据专业关键词匹配 / 只根据目标生成固定模板 / 推荐结果无法解释原因 / 忽略用户现实约束。

## 用户一：南航AI中外合办 大一 保研+大厂双目标 雅思6.5硬约束

- 学校：南京航空航天大学 / 专业：人工智能（中外合作办学）/ 培养模式：4+0不出国 / 年级：大一
- 目标：第一 保研资格 / 第二 互联网大厂算法岗实习
- 当前：Python基础弱 / 无科研 / 无竞赛 / 数学正常
- 硬约束：大一升大二前雅思≥6.5 / 每天可投3小时 / 家庭支持较强

**核心矛盾**：多目标竞争型。不是"不知道参加什么"，而是"如何在有限时间同时满足英语硬指标+保研竞争力+AI技术积累+大厂实习准备"。

**正确推荐逻辑**：
1. 第一优先级 英语达标（硬约束，失败影响后续发展，提升权重）
2. 第二 AI基础能力建设（Python/C++/数据结构/LeetCode/数学，保研+大厂共同依赖）
3. 第三 进实验室探索科研（CV复现/NLP小项目/大模型应用）
4. 降级：数学建模（可参加但非主路线）/ ACM（长期价值高但大一不该大量投入冲击）

**期待系统输出**："你的情况属于多目标竞争型用户。目前最大风险是同时追求保研和就业导致路线分散。建议大一优先完成英语门槛和AI基础能力建设，再逐步增加科研投入。"

## 用户二：复旦AI 大一 创业型 不保研

- 学校：复旦大学 / 专业：人工智能 / 年级：大一
- 目标：本科期间创业开发AI产品 / 不考虑保研
- 当前：成绩中上 / 兴趣：产品设计/软件开发/AI应用

**应避免**：不能因"AI专业"直接推荐发论文/做科研/ACM/数学建模（目标不同）。

**正确判断**：核心价值是AI技术转化能力，非学术竞争。
- S级：AI工程能力（Agent开发/Web应用/模型调用/产品原型/开源项目）
- A级：创业比赛/用户研究/产品实践
- 降级：论文路线（与目标相关性低）

**期待输出**："你的目标不是学术深造，因此科研论文不是当前最高收益路径。建议优先构建AI产品能力和工程能力。"

## 用户三：普通211计算机 大二 冲顶级研究生 已有竞赛

- 学校：普通211 / 专业：计算机科学 / 年级：大二
- 目标：保研/考研冲击顶级高校计算机方向
- 已有：数学建模省奖 / 蓝桥杯省奖 / 成绩前20%

**应发现**：不是零基础，已有竞赛经历。继续推数学建模/蓝桥杯=低收益重复投入。

**正确推荐**：
- 提高科研经历权重（联系导师/做科研项目/论文阅读/复现实验）
- 补充提高GPA（顶级院校筛选看综合竞争力）

**期待输出**："你已经完成竞赛基础证明，继续重复参加类似比赛收益下降。当前阶段更需要科研成果和学术能力提升。"

## 用户四：普通一本经管 大三 就业型 时间少

- 学校：普通一本 / 专业：工商管理 / 年级：大三
- 目标：毕业进入互联网运营岗位
- 已有：CET-6 / Excel熟练 / 无编程基础 / 每天可投1小时

**应避免**：因成长系统默认"所有人都该保研"导致错误推荐。

**正确判断**：目标就业+大三+时间有限。
- S级：岗位能力建设（数据分析/SQL/用户运营案例/实习）
- A级：行业项目经历
- 降级：考研路线/科研论文

**期待输出**："你的目标是就业而不是升学，因此当前最重要的是形成岗位竞争力，而不是投入长期学术路线。"

## 用户五：清华计算机 大三 已有顶级科研 直博型

- 学校：清华大学 / 专业：计算机科学 / 年级：大三
- 目标：人工智能方向直博
- 已有：SCI论文一篇 / 顶会合作经历 / GPA优秀

**必须避免**：推荐学Python/参加竞赛/做入门项目（严重错误）。

**正确判断**：已超基础建设阶段。
- S级：导师联系/研究方向深化/论文投稿/研究计划
- A级：博士申请准备
- 降级：所有基础学习任务

**期待输出**："你的基础能力已经达到较高水平，继续投入入门课程和普通竞赛边际收益较低。当前阶段应该集中资源提升研究深度和申请竞争力。"

## 总验收标准

若系统面对以上 5 用户仍输出"数学建模/ACM/科研/英语/夏令营"类似排序 → 仍是关键词推荐系统，不合格。

**真正合格的成长决策系统必须**：
1. **同一机会在不同用户价值不同**：数学建模对 AI大一=A / 对数学专业=S / 对已有科研大三=低优先级。
2. **同一用户随阶段变化推荐变化**：大一推Python基础 / 大三推导师联系。
3. **能识别用户约束**：雅思硬要求必须提权。
4. **能识别目标冲突**：保研+大厂实习需时间分配而非堆推荐。
5. **每个推荐必须回答**：为什么是我 / 为什么现在 / 为什么比其他事重要。

满足以上才算具备真正个性化决策能力，非伪智能推荐。
