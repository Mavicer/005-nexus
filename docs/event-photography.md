# Event detail photography

Use strong, recognisable event photography, not a completeness quota. The user approved RoboMaster pit-work photographs and the Huawei ICT final competition-room photograph on 2026-10-31. A sharp subject, characteristic equipment, lighting and a clean crop matter as much as pixel dimensions. Reject logos, certificates, award groups, dense posters, generic stock photos and weak screenshots. Events without an accepted image retain the original header. Never substitute another event or track just to fill a space.

## Layout and loading

Artwork is an absolute decorative layer; its dimensions do not depend on image decoding. Desktop artwork fades from the right, mobile artwork has a reserved 230 px area above the text. Native eager/high-priority loading is used on detail pages. Pointer hover, keyboard focus and touch on discovery links prewarm the corresponding image; repeated requests are deduplicated, and speculative failures can retry. Existing route prefetch remains enabled. Images are kept out of catalog cards.

The remaining catalog entries have no accepted image yet. Earlier search candidates are intentionally excluded; continue the same quality threshold when suitable originals become available.
