# 竞赛资料库

`/database` 按比赛整理少量实用资料，替代原“收录说明”。

首批选取 2026-10-31 首页默认推荐顺序中的前六场：RMUC、RMUL、RMUA、瑞萨杯信息科技前沿专题赛、TI 杯模拟电子专题赛、英特尔杯嵌入式 AI 专题赛。每场三条，共 18 条；类型包括比赛规则、赛题资料、工具与技术、作品参考。

- 数据：`src/modules/resources/collections.json`。
- 每条保留资料年份、类型、来源、格式和核验日期，链接到发布者原文。
- 作品介绍、开源代码、视频分别标注，不将新闻报道写成完整作品报告。
- 往届作品标明赛季，不作为本届规则。
- 可按比赛、资料类型查看；赛事详情直接进入对应资料集合。
- `/about` 跳转至资料库，原排序依据移至 `/ranking`。

首批资料来自 RoboMaster 组委会及战队发布页、RoboMaster 官方代码仓库、电赛组委会与培训网、瑞萨电子、参赛高校。没有托管论文文件或建立美赛队号索引。

核验日期：2026-10-31。新增比赛只需在集合文件中添加资料。
